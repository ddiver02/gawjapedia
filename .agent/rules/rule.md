나는 Google Antigravity 기반의 웹앱을 개발하려고 합니다. Claude-Sonnet 4.5 모델을 사용하여 아래 각 단계별로 설명, 코드, 그리고 그 코드의 의미를 단계적으로 설명해 주세요. 코드는 사용자가 직접 이해하고 실행할 수 있도록 자세히 풀어 쓰고, 가능한 오류 예시와 해결법도 함께 제시해 주세요.

---

1) **환경 설치 및 초기 설정**
- Windows/macOS/Linux 기준으로 Antigravity 설치 방법을 단계별로 알려 주세요.
- 설치 후 Antigravity를 처음 실행하고 Gmail 계정으로 로그인까지 완료하는 전체 흐름을 설명해 주세요.
- 프로젝트 디렉토리를 만들고 Antigravity 에디터를 여는 명령과 설정 방법도 상세히 설명해 주세요.

---

2) **웹앱 프로젝트 생성 + 구조 설명**
- Antigravity에서 새 웹앱 프로젝트를 만들기 위한 프롬프트 및 명령을 알려 주세요.
- 생성할 디렉토리/파일 구조를 설명해 주세요 (예: pages/, components/, public/ 등).
- 각 파일의 목적을 설명하고, Antigravity 에이전트가 어떤 코드를 자동으로 생성하는지 구분해서 작성해 주세요.

---

3) **프론트엔드 UI 기본 구현**
- React/Next.js 기반으로 간단한 웹페이지 UI를 만듭니다:
  * 헤더 컴포넌트 (로고 + 네비게이션)
  * 메인 페이지 기본 문구
  * 간단한 버튼 클릭 이벤트
- 각 UI 컴포넌트 코드 + 코드 설명을 작성하고,
  어떤 부분이 React/JSX 문법인지 자세히 해설해 주세요.
- CSS 또는 Tailwind 등을 적용하는 방법도 보여 주세요.

---

4) **백엔드 API 라우트 구현**
- “/api/hello” 라우트를 생성하고, JSON 응답을 제공하는 코드를 작성해 주세요.
- JSONPlaceholder 같은 외부 API에서 데이터를 받아오는 예제 코드를 작성해 주세요.
- 해당 API를 프론트엔드에서 호출하여 화면에 표시하는 부분까지 설명해 주세요.

---

5) **Antigravity 에이전트와 함께 테스트 + 디버깅**
- 작성한 UI/라우트가 정상 작동하는지 확인하는 테스트 방법을 알려 주세요.
- 개발 중 발생할 수 있는 오류(예: 컴포넌트 렌더 오류, API 호출 실패 등)의 원인과 해결 방법을 구체적인 예시 코드와 함께 설명해 주세요.
- Antigravity의 브라우저 통합 테스트 기능을 활용해 자동 검증하는 예도 보여 주세요.

---

6) **배포 준비 및 실행**
- 빌드 스크립트를 만들고 최적화 설정을 설명해 주세요.
- 실제 배포(예: Vercel/Netlify 등)까지 진행하는 전체 프롬프트/코드/단계별 체크리스트를 작성해 주세요.
- 배포 후 필요한 점검 포인트도 제시해 주세요.

---

각 단계별로 실행 가능한 명령, 코드 프래그먼트, 그리고 그 코드의 의미를 명확하게 설명하시고, 에러가 생겼을 때 어떤 메시지가 나올지 예시와 그 해결 방법도 반드시 포함해 주세요. Claude-Sonnet 4.5 모델로 이 전체 흐름을 단계적으로 안내해 주세요.
