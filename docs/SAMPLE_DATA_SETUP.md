# Google Sheets 샘플 데이터 입력 가이드

## 🚨 현재 발생한 에러

```
Unable to parse range: Sheet1!A:AC
```

**원인**: Google Sheets가 비어있거나 시트 이름이 잘못되었습니다.

---

## ✅ 해결 방법 (5분 소요)

### Step 1: Google Sheets 열기

1. 브라우저에서 다음 URL 접속:
```
https://docs.google.com/spreadsheets/d/1hdoslVt7F_H6FxROu3a8LoC7pj9Dijws1iaYZWuTZHQ/edit
```

2. 로그인 (Google 계정)

---

### Step 2: 시트 이름 확인/변경

1. 좌측 하단의 **시트 탭** 확인
2. 시트 이름이 **"Sheet1"**이 아니면:
   - 시트 탭 우클릭
   - "이름 바꾸기" 선택
   - `Sheet1` 입력
   - 확인

![Sheet Name](https://via.placeholder.com/600x200?text=Sheet+Name:+Sheet1)

---

### Step 3: 헤더 행 입력

**A1 셀**에 커서를 놓고 다음을 **한 줄씩** 붙여넣기:

```
ID	이름	제조사	카테고리	내용량(g)	가격(원)	평점	열량(kcal)	탄수화물(g)	단백질(g)	지방(g)	당류(g)	나트륨(mg)	식이섬유(g)	포화지방(g)	트랜스지방(g)	콜레스테롤(mg)	칼슘(mg)	철분(mg)	비타민C(mg)	비타민E(mg)	비타민A(μg)	칼륨(mg)	마그네슘(mg)	아연(mg)	엽산(μg)	티아민(mg)	리보플라빈(mg)	니아신(mg)
```

> ⚠️ **주의**: 위 텍스트를 복사하면 자동으로 탭으로 구분되어 각 셀에 들어갑니다.

---

**A2 셀**부터 아래 데이터를 **한 번에 복사 붙여넣기**:

```
1	오리온 초코파이	오리온	과자	396	3500	4.5	480	64	5	22	32	200	2	11	0	5	40	2	0	0	0	150	30	1	10	0.1	0.1	1

3	롯데 ABC초콜릿	롯데제과	초콜릿	50	1200	4.3	265	30	3.5	15	28	60	1.5	9	0	10	80	1.5	0	1	20	180	35	0.8	8	0.06	0.12	0.5
```

**결과 확인:**
- A열: ID (1, 2, 3, 4, 5)
- B열: 이름 (오리온 초코파이, ...)

- ...

---

### Step 5: 권한 확인

1. 우측 상단 **"공유"** 버튼 클릭
2. "링크가 있는 모든 사용자"가 **"뷰어"** 이상 권한 확인
3. 또는 서비스 계정 이메일 추가:
   ```
   (your-service-account-email)@(your-project-id).iam.gserviceaccount.com
   ```
   - 권한: **편집자**

## 🐛 문제 해결

### 1. "시트를 찾을 수 없습니다"
- 시트 이름이 정확히 `Sheet1`인지 확인 (대소문자 구분)
- 시트가 삭제되지 않았는지 확인

### 2. "권한이 없습니다"
- 서비스 계정 이메일이 추가되었는지 확인
- 권한이 "뷰어" 이상인지 확인

### 3. "데이터를 읽을 수 없습니다"
- A1 셀에 헤더가 있는지 확인
- 데이터가 A2부터 시작하는지 확인
- 빈 행이 없는지 확인
